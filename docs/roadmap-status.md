# Соответствие дорожной карте

| Направление | MVP | Следующие этапы |
|---|---|---|
| Единый каталог | Модели, марки, характеристики и предложения | Редакционная нормализация данных, фотографии |
| Выбор техники | Фильтры, сравнение, избранное | Геопоиск, синонимы, рекомендации |
| Обзоры и доверие | Журнал, отзывы с модерацией | Рейтинг дилеров, подтверждение покупки |
| Кабинет | Сессии, свои предложения и заявки | Интеграции, массовая загрузка |
| Тарифы | Административное назначение и лимиты | Платежи, биллинг, реклама |
| Лиды | Сохранение, назначение, стадии | Уведомления, счета, CRM |
| Экосистема | Типы запросов сервис/трейд-ин | Отдельные модули сервиса, запчастей и акций |
| Инфраструктура | Один Node-сервер и SQLite | PostgreSQL, очереди, поиск, SSR |
| Мобильная часть | Адаптивный веб-интерфейс | Нативные клиенты и push |

MVP не выдаётся за полную реализацию дорожной карты. Публикация дилера и наличие импортированы из старой БД, а не проверены звонком или актуализацией остатков.
