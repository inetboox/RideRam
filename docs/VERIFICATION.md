# Проверка перед передачей

Проверено на Node.js v22.16.0 (Linux): npm run build; npm test (зависимости уже были установлены). Интеграционный тест проходит без ошибок и покрывает каталог, вход, сессии/CSRF, разграничение прав дилеров, изменение предложений, создание и обработку заявок, модерацию отзывов, публикацию контента и повторное открытие SQLite. Тест работает на отдельной временной базе.

Проверен реальный запуск npm entrypoint в development и production: главная страница, deep-link /catalog и API с 381 импортированной моделью возвращают HTTP 200. Проверена отдача преобразованного React-модуля в development.

Визуальное отображение, полный пользовательский путь в браузере и работа на Windows/macOS не проверялись. Нагрузочное тестирование и профессиональный аудит безопасности не выполнялись. SQLite в Node 22 помечен экспериментальным — предупреждение ожидаемо.

Подробные результаты: verification.json. Полный охват дорожной карты не заявляется: см. roadmap-status.md и раздел ограничений в README.md.
