# Rideram — React-маркетплейс мототехники

Рабочий локальный MVP по предоставленной дорожной карте, а не полная реализация всех её этапов. React 19 + React Router + Vite, Express 5, SQLite (встроенный модуль Node). Пользовательский интерфейс на русском, адаптивная вёрстка. Отдельная установка MySQL/PostgreSQL не нужна.

## Быстрый запуск

Нужен Node.js **22.16+** (рекомендуется актуальный Node 22 LTS или 24 LTS) и npm. Распакуйте содержимое архива в пустой каталог репозитория:

```sh
npm install
npm run dev
```

Откройте http://localhost:3000. При первом запуске сервер создаёт SQLite, импортирует каталог и печатает в терминале **два новых случайных пароля**: для `dealer@rideram.local` и `admin@rideram.local`. Сохраните их: при следующем запуске они не показываются. Старые пароли из SQL намеренно не перенесены.

Можно перед первым запуском скопировать `.env.example` в `.env` и задать собственные `DEALER_PASSWORD` и `ADMIN_PASSWORD` длиной не менее 12 символов. Изменение этих переменных после создания базы НЕ меняет существующие пароли.

## Сборка и сервер

```sh
npm run build
npm start
npm test
```

`npm run dev` запускает и API, и Vite одним процессом. `npm start` раздаёт собранную папку `dist` и API на одном порту. Дефолтный HOST — 127.0.0.1; для контейнера задайте HOST=0.0.0.0. Для продакшена обязательны TLS reverse proxy, NODE_ENV=production, COOKIE_SECURE=true. Не открывайте HTTP-сервер с реальными персональными данными в интернет.

## Реализовано

- Главная, каталог, страницы моделей и марки через фильтр, пагинация, поисковая строка.
- Фильтры: категории, марки, цена предложения, объём, назначение, привод, трансмиссия, город предложения, наличие; сортировка по имени/цене/предложениям.
- Избранное, до четырёх моделей в сравнении, сохранённый поисковый запрос — в localStorage текущего браузера.
- Карточки с текстом, характеристиками, предложениями дилеров и ссылкой на обзоры; неподтверждённые цены явно обозначены. Без выдуманных фото, обзоров, рейтингов и цен.
- Заявки на консультацию, тест-драйв, бронь, трейд-ин или сервис сохраняются на сервере. Заявка на конкретное предложение видна соответствующему дилеру. Общий запрос без предложения виден только администратору, который может назначить дилера.
- Кабинет с логином/паролем: реальные сессии в HttpOnly cookie, CSRF, scrypt-хеши, ограничение попыток входа, серверное разграничение доступа.
- Дилер создаёт/редактирует свои предложения, цены, наличие, статус; видит заявки, меняет стадию и заметки. Статистика просмотров относится к страницам моделей, а не уникальным покупателям или показам объявления.
- Администратор редактирует модели (включая JSON характеристик и HTTPS URL фото), добавляет дилеров, меняет их тариф/публикацию, публикует обзоры и модерирует отзывы. При добавлении дилера учётную запись создают отдельной CLI-командой.
- Тарифные лимиты: Старт — 20, Рост — 100, Партнёр — без лимита. Это локальная логика лимитов, не оплаченная подписка. Проверенность дилера устанавливается администратором, а не автоматически за оплату.

## Учётные записи

Сбросить пароль или создать учётную запись дилера (сначала добавьте дилера в админ-панели и возьмите его ID):

```sh
# bash / macOS / Linux
NEW_USER_PASSWORD="strong-password-at-least-12" npm run create-user -- dealer@example.com dealer 1
NEW_USER_PASSWORD="another-strong-password-12" npm run create-user -- admin@rideram.local admin
```

PowerShell:

```powershell
$env:NEW_USER_PASSWORD="strong-password-at-least-12"
npm run create-user -- dealer@example.com dealer 1
Remove-Item Env:NEW_USER_PASSWORD
```

Команда сбрасывает старые сессии пользователя. Пароли не передавайте клиентскому JavaScript, не включайте `.env` и папку `var` в git.

## Данные и резервные копии

`data/seed.json` — очищенный импорт прикреплённых SQL. При первом запуске он переносится в `var/rideram.sqlite`. Дальнейшие изменения хранятся в SQLite и не перезаписываются seed-файлом. DATA_DIR задаёт другой каталог БД. Остановите сервер перед копированием папки `var`; для онлайн-бэкапа используйте SQLite backup API. Удаление `var` уничтожит все локальные заявки, пользователей, отзывы и изменения каталога — не делайте этого для сброса пароля.

Импорт: **381 модель, 77 марок, 5 категорий, 1 дилер, 1 предложение**. Единственное предложение в SQL: 250 000 ₽, остаток 7; это исторические значения, а не подтверждение текущего наличия. У 254 моделей корректные JSON-характеристики; 115 моделей не имеют категории, 119 — марки. Неизвестные значения не подменены догадками. Некорректные Base64/JSON и сообщения ошибок сборщика отфильтрованы; подробности — `docs/import-report.json`. Все четыре переданных SQL совпадают по SHA-256, повторный импорт не производился. Исходные дампы и их открытые пароли не включены в архив.

В схеме SQL отсутствуют фотографии. SVG в интерфейсе — условные иллюстрации, не изображения реальных моделей. Реальные фотографии можно добавить в модели через админку по HTTPS URL. Локальная загрузка файлов не реализована. Старые новости не опубликованы без редакторской проверки. Не классифицированные модели доступны в общем каталоге без категории.

## Что пока НЕ реализовано из дорожной карты

Мобильные приложения, PostgreSQL/Redis/Elasticsearch и микросервисы, SSR и полноценное SEO отдельных карточек, оплата тарифов/лидов, платное ранжирование, рекламные кампании, email/SMS/push, чат, загрузка фото/документов, геолокация/радиус, поиск с исправлением опечаток и синонимами, отдельные каталоги запчастей/сервиса/акций, интеграционное API дилеров с ключами, рейтинги дилеров и проверенные покупки, клиентская регистрация и синхронизация избранного между устройствами. Форма заявки не означает реальное бронирование или запись в расписание; требуется подтверждение дилером. Обзоры заполняются редактором через админку.

Страница обработки данных — технический шаблон. До публичного запуска заполните реквизиты оператора и сроки обработки, проверьте согласия и юридические требования. Необходимо провести аудит безопасности, нагрузочное тестирование, обновление зависимостей, мониторинг, защиту от спама и организовать резервирование. Ограничитель запросов работает в памяти одного процесса. Эта SQLite-реализация подходит для локального MVP/одного инстанса, не для высоконагруженного кластера.

## Структура

`src` — React-интерфейс и CSS; `server` — Express/API, SQLite, авторизация и CLI; `data` — очищенные данные; `tests` — интеграционный тест; `docs` — отчёт импорта и соответствие дорожной карте; `dist` — готовая клиентская сборка. Модули node_modules не вложены, устанавливаются через npm; package-lock.json фиксирует версии. Исходный текст дорожной карты приложен как `roadmap-source.txt`.
